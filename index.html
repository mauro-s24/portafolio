Freelance · Real client · Built from scratch to production

Lucky Fight – Online Raffle Ticket Platform

A complete raffle sales platform: database, payments, notifications, security and deployment, all built from zero and live in production.

  • Relational schema in PostgreSQL (Supabase) with atomic SQL functions (FOR UPDATE SKIP LOCKED) for race-condition-free inventory reservation and unique random number generation.
  • Row Level Security and security-definer functions: the public only sees aggregated data and the service key stays on the backend.
  • Wompi payments: integrity signature for hosted checkout, SHA-256 webhook validation, amount verification and idempotency against duplicate events.
  • Next.js (App Router) API routes with server-side validation and IP rate limiting; Vercel Cron Jobs release expired reservations.
  • Transactional emails with Resend (verified domain, SPF/DKIM); Vercel + GitHub CI, Cloudflare DNS and hardened HTTP headers (CSP, HSTS, X-Frame-Options).
  • Responsive Tailwind UI with an infinite-scroll gallery, validated forms and an auth-protected admin panel.
